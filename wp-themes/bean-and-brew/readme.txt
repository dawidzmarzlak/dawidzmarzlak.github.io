== Description ==

Bean & Brew is a Full Site Editing block theme tailored for small food-and-drink businesses.

Features:
* 5 ready-to-use page sections (Hero, Story, Menu with tabs, Location, CTA)
* Self-hosted DM Serif Display, DM Sans, and Caveat (no Google Fonts request leak)
* Mobile-responsive without external CSS frameworks
* Dependency-free: no plugins required for the default look
* Fully customizable via Site Editor → Styles
* Accessible: tab pattern includes ARIA roles, scroll reveals respect prefers-reduced-motion

== Installation ==

1. Upload the theme directory to /wp-content/themes/
2. In WP admin, go to Appearance → Themes and activate Bean & Brew
3. Go to Settings → Reading and set "Your homepage displays" to a static page using the Front Page template
4. Edit content via Site Editor (Appearance → Editor)

== Frequently Asked Questions ==

= Do I need any plugins? =

No. Default appearance and layout work with WordPress core only.

= Can I change the color palette? =

Yes — Appearance → Editor → Styles → Colors → Palette.

= Can I add my own sections? =

Yes — patterns are inserted via the block inserter under the "Bean & Brew" category.
